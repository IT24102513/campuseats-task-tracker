# CampusEats Task Tracker

A simple task tracker for the CampusEats project.

## Features

- Manage CampusEats development tasks
- Track tasks such as menu development, orders API, and user login
- Use Git and GitHub for collaboration

## Tasks

- Design the menu screen
- Build the orders API
- Add user login

## Technologies

- Git
- GitHub
- JavaScript
- GitHub Actions

## Purpose

This project is created for the SE3090 Software Engineering Frameworks Lab 08 to practise Git, GitHub, branching, pull requests, CI/CD, code quality, and security.
